# Security policy

[English](SECURITY.md) · [简体中文](SECURITY.zh-CN.md)

Report security issues privately through the repository's **Private vulnerability reporting** feature. Do not disclose exploitable details, API keys, real project files, or user media in a public Issue.

Include the affected version, reproduction steps, potential impact, and any practical mitigation. After confirming the report, maintainers will communicate a remediation and disclosure plan.

MotionMaster listens on local address `127.0.0.1` by default. If you expose it to a LAN or the public internet, configure authentication, TLS, upload limits, and data-directory permissions appropriate for that environment.
