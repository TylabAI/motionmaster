# MotionMaster interface languages

MotionMaster provides a runtime Chinese / English interface switch in the top-right toolbar.

- On first launch, the studio follows the browser language: Chinese browsers use Simplified Chinese and other browsers use English.
- The user can switch between `中文` and `English` without reloading the page.
- The selected language is saved in local storage under `motion-master-locale-v01`.
- Product UI, dialogs, accessibility labels, placeholders, timeline controls, asset classification, and ASR settings are translated.
- Project names, imported captions, transcript text, card copy, and other user-authored content are preserved as entered.

The implementation lives in `apps/studio-web/src/i18n.tsx`. Add new fixed UI labels to `messages`; add parameterized messages to `rules`. Keep project-authored text outside the UI dictionary so changing the interface language never rewrites project data.

## 中文说明

MotionMaster 在右上角工具栏提供中文 / English 即时切换。

- 首次启动跟随浏览器语言：中文浏览器默认显示简体中文，其他浏览器默认显示英文。
- 切换无需刷新页面，选择会保存到本机浏览器。
- 产品界面、对话框、无障碍标签、占位提示、时间轴、资产分类和 ASR 设置会随语言切换。
- 项目名称、导入字幕、转录文字、卡片文案等用户内容保持原样，不会因界面语言变化而被改写。
